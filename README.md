# TM Cobots USD

USD assets for Techman Robot cobots.

| Directory | Series |
|---|---|
| `cobot/` | TM AI Cobot |
| `cobot_s/` | TM AI Cobot S |

`*.usd` files are stored with [Git LFS](https://git-lfs.com).

## Get the USD files

These steps assume you already have this repository on disk. Install Git LFS, run `git lfs install`, then run `git lfs pull` in this repository.

1. Install Git LFS from <https://git-lfs.com>.
2. Enable Git LFS once:

   ```bash
   git lfs install
   ```

3. In this repository, download the USD files:

   ```bash
   git lfs pull
   ```
